# Motor Simulation with Plotting

This simulation file (`motor_simulation.cpp`) simulates motor control and plots target vs actual position.

## How to Use

### 1. Adjust Target Position

Open `motor_simulation.cpp` and find the line:
```cpp
params.target_position = 2.0;  // Change this value to set target position (radians)
```

Change the value to your desired target position in radians.

### 2. Compile and Run

```bash
# Compile (requires Eigen library)
g++ -std=c++17 -I/path/to/eigen motor_simulation.cpp -o motor_simulation

# Run
./motor_simulation
```

This will generate `motor_simulation_data.csv` with the simulation data.

### 3. Plot Results

**Option 1: Using Python script (recommended)**
```bash
python plot_motor_data.py
```

**Option 2: Using Excel/Matlab**
Open `motor_simulation_data.csv` in Excel or Matlab and plot the columns.

## Output Files

- `motor_simulation_data.csv`: CSV file with time, positions, velocities, and control voltage
- `motor_simulation_plot.png`: Plot image (generated by Python script)

## Adjustable Parameters

In `motor_simulation.cpp`, you can adjust:
- `params.target_position`: Target position in radians (main variable to adjust)
- `params.simTime`: Simulation duration in seconds
- `params.Ts`: Sampling period
- Control parameters (wf_vel, wf_pos, umax, etc.)

## Linking

The simulation file includes `motor_control_full.cpp` using a preprocessor guard to avoid duplicate main() functions. Both files are linked together through the include mechanism.
